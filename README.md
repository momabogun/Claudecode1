# Claudecode1

My workspace for experimenting with Claude Code. It contains a Vue 3 + Vite starter app.

## Project structure

```
Claudecode1/
└── momo-project/   # Vue 3 + Vite app
```

## Getting started

Requires Node.js `^22.18.0` or `>=24.12.0`.

```bash
cd momo-project
npm install
npm run dev
```

## Scripts

| Command           | Description                      |
| ----------------- | -------------------------------- |
| `npm run dev`     | Start the dev server             |
| `npm run build`   | Build for production             |
| `npm run preview` | Preview the production build     |
| `npm run format`  | Format `src/` with Prettier      |

## Tech stack

- [Vue 3](https://vuejs.org/)
- [Vite](https://vite.dev/)
- [Prettier](https://prettier.io/)
